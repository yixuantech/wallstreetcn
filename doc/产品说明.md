# AI盘报 · 产品说明

> 为你一个人发行的私人财经日报。
> 选题帮你筛，数字帮你量，黑话给你讲，判断陪你记——但报纸永远不替你下单。

---

## 一、出发点：一个散户的真实困境

产品作者就是一个普通散户：有本职工作，没有财经背景，拿着几只股票。

每天面对的现实是——

- 微信群、公众号、行情软件推送上百条资讯，**没时间读，也不敢不读**
- 勉强读了，"主动调整""PPI同比""社融坍缩"——**每个字都认识，连起来不知道和我有什么关系**
- 最怕的是漏事：持仓股晚间发了立案公告，**次日一字跌停了才知道**
- 周末想复盘，没有材料、没有记录，全凭印象
- 看了十年股评，判断力原地踏步——**亏钱不是因为信息少，是因为每次判断都没有记分**

市面上的工具呢？行情软件给你更多资讯，大V给你更多观点，荐股软件直接给你代码——**没有一个工具替你读、给你讲、还不骗你**。

AI盘报就是为填补这个空缺而做的。

## 二、解决的问题（六层，从浅到深）

| # | 问题 | 解决机制 |
|---|------|---------|
| ① | 资讯过载，没时间筛 | **分诊**：🔴🟡🟢⚪标签把300条筛成3条；无事则沉默 |
| ② | 专业内容看不懂 | **说人话**翻译 + **逻辑链**（事件→业务→财务→估值）+ **概念卡** |
| ③ | 怕漏重大事件 | 早中晚**三段巡检** + 日历节点提前7天 + 夜间🔴**紧急警报** |
| ④ | 信息与持仓断裂 | 一切解读终点是"**传导到你的票**" + **观察点**（盯什么、有结果了吗） |
| ⑤ | 情绪化决策（散户亏钱主因） | **情绪刻度**给历史同类日数据锚定；盘中异动必须**三件套**（异动+定级+盯什么），禁止裸价格播报 |
| ⑥ | 判断力无法积累 | **主线追踪**（连续叙事）+ **判断记分牌**（每天验对错）+ 周报胜率 |

前三条解决"今天的焦虑"，后三条解决"三年的成长"。

## 三、产品形态：七栏目，一天的新闻事业

```
🌅 晨报   07:30  盘前预判：全球要闻（附历史模式锚）+ 主线地图 + 今日预判 + 自选股晨巡
⚡ 午间快讯 11:35  有事才发：上午新增🟡级事项，三件套护栏
🌙 晚报   17:30  盘后复盘：收盘全景 + 情绪刻度 + 判断记分牌 + 观察点状态
📊 数据解读 18:30  宏观数据日专刊：三对照（实际vs预期vs前值）+ 历史分位 + 概念卡 + 持仓联动
🚨 紧急警报 20:30  只响🔴：晚间暴雷公告，提前12小时
📖 周报   周六   判断胜率 + 主线周演进 + 观察点结算 + 下周日历
```

日均约3条，必读仅晨晚2条。周末/节假日静默。**巡检可以一天多次，说话默认沉默**。

## 四、核心特色（与一切"炒股工具"的区别）

**1. 分诊，不是推送**
我们不给您更多资讯，我们替您读完然后告诉您：您的票今天没事（🟢，三行收工）、有一件事（🟡，逐条讲透）、出大事了（🔴，急电）。90%的日子，您30秒处理完毕。

**2. 数字是我们算的，话是AI说的，决定是您做的**
- 规则引擎（代码）负责一切硬结论：标签判定、估值分位、预期修正、三对照、情绪分值——**可复算、零幻觉**
- AI只负责翻译与解释：说人话、逻辑链、传导分析——并且被三条铁律锁死：**不编数字、不给买卖指令、不确定必须标注**
- 升级权单向：AI可以把🟢升级为🟡（怕您漏事），永远不能降级（怕它和稀泥）

**3. 可溯源**
每条解读都带原文链接。AI说的每个数字都能点回去验证——**您不必信任我们，您只需要验证我们**。

**4. 可验证——全市场独一份的"更正文化"**
判断记分牌每天给昨天的预判打分：方向对了吗、板块兑现了吗、哪条利好是噪音。**AI判断错了，第二天报纸登出来说它错了**。市面上所有产品都在展示"我多准"，只有这份报纸敢每天公布自己的胜率。

**5. 有记忆**
观察点（说要盯的事，系统帮您挂着直到有结果）、主线追踪（市场是一部连载，不是每天互相矛盾的碎片）、判断流水（对错的账本）。**用得越久，越懂您的持仓。**

**6. 诚实到刻板**
数据拿不到就标⚪"数据缺失，无法确认有无事项"——绝不假装没事（"确认无事"和"不知道有没有事"是两回事）；无机构覆盖的冷门股就明说"无锚，禁止定量结论"。**宁可难看，不可骗您。**

## 五、您将获得什么

**每天**：30秒的确定感（标签即结论）、每条资讯的"懂了"（翻译+逻辑链+预期对照）、暴雷前12小时的提前量、暴跌夜的历史锚（同类恐慌日次日反弹概率58%——用数据把"慌"钉住）。

**每周**：一个胜率数字（判断力第一次可量化）、一张更新的市场地图（主线连载）。

**三个月后**：一本私人财经词典（概念卡）、一个模式库（历史模式锚：别人第一次见的局面，您是第二次）、一套被校准过的直觉（记分牌攒出来的）。**这三样东西市面上买不到，只能攒。**

## 六、产品边界（同样重要）

AI盘报**不做什么**：

- **不荐股、不预测涨跌点位、不给买卖指令**——功能宪法第一条。它说的永远是"盯什么"，从不说"买/卖/拿"
- **不承诺盈利**——它提高您的知情质量，不改变市场风险
- **不做盘中实时监控**——分钟级推送违背分诊哲学（高频打断制造情绪炸弹），且对非日内交易者无意义
- **不隐藏数据的缺失与不确定**——⚪就是⚪，"不确定"必须写在纸上

**一句话：它是受托代理人，不是操盘手。方向盘永远在您手里。**

## 七、技术形态（一段话说完）

数据全部来自公开免费接口（东方财富/腾讯行情/华尔街见闻早餐FM），规则引擎用Python计算硬结论，DeepSeek负责翻译与解释，PushPlus送达微信，Linux cron 定时驱动，全程无人值守，单次运行成本以分计。架构与实现细节见《实现规划》。
