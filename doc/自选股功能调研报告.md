## 0. 设计哲学（先读这章，它是所有设计的仲裁标准）

### 0.1 一句话本质

> **它是插在你与市场信息之间的"受托代理人"：替你读、替你算、给你讲、陪你记——但永远不替你决定。**

角色是机构里给基金经理写晨报的分析师助理：把隔夜发生的一切过滤、定级、翻译好，最后说"今天您需要看这个，其余不用管"。**边界就是价值**——越过"替你决定"的线，工具就变成风险源。

### 0.2 方法论：事实与观点的严格分离

```
事实（数字、日期、颜色标签、预期锚、成色）→ 规则引擎
     可验证、可审计、故障自曝（⚪）、确定性强

解释（黑话翻译、传导链、预期差解读、复盘对照）→ AI
     唯一能做翻译和推理的层，被三个禁区拴住：
     ① 不编数字  ② 不给买卖指令  ③ 不确定必须标注

决策 → 只属于用户
```

### 0.3 功能宪法（后续所有实施争议的裁决表）

| 争议场景 | 宪法裁决 |
|---------|---------|
| 要不要加盘中实时推送？ | 不属于"盘前代理人"角色 → 不加（独立立项除外） |
| AI 要不要直接给买卖建议？ | 决策权在用户 → 永不 |
| 这个数字让 AI 估算一下行不行？ | 凡事实归规则 → 不行，宁缺并标注 |
| 今天没事，要不要写点分析凑版面？ | 沉默是默认值，发言需要证据 → 不写 |
| 冷门股没有一致预期怎么办？ | 成色分级、无锚降级 → 不编锚 |

### 0.4 AI 应用范畴定位

- **应用形态**：Agentic Workflow（智能体工作流）——固定管线里嵌 LLM 步骤，非自主 Agent；流程确定性靠代码，翻译推理靠模型
- **行业领域**：FinTech · 智能投研（个人版）——不是智能投顾（不给建议）
- **技术范式**：数据锚定生成（Grounded Generation）——规则+LLM 混合架构，反幻觉
- **人机关系**：决策支持系统（增强智能）——止步于"情报官"，不是决策替代

### 2.4 个股行情（v2 新增）

复用现有 `push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&secids={secids}&fields=f2,f3,f12,f14`（与 [fetcher.py](../src/fetcher.py) 全球指数同一端点，仅换 secid）。实测：`f2`=最新价、`f3`=涨跌幅、`f14`=名称。**工程上可直接复用现有函数**。

### 2.5 预期温度计数据（v2 新增，主锚升级）

| 维度 | 来源 | 关键字段（已实测） |
|------|------|------------------|
| ① 一致预期水平 | F10 `PC_HSF10/ProfitForecast/PageAjax` → `jgyc` | "近六月平均"：2026E EPS 67.91 / PE 18.73，多年预测曲线，每日更新 |
| ② 修正方向 | 同上 → `yctj_list` | `EPS`(本月) vs `EPS_LASTMONTHS`(上月)；茅台实测：68.76→67.91 = **-1.24% 下修**（三个预测年同步下修） |
| ③ 业绩对照 | 业绩预告/快报（公告+资讯）+ ① | 预告隐含增速 − 一致预期隐含增速 |
| ④ 估值分位 | `RPT_VALUEANALYSIS_DET` | 茅台2096条日频：`PE_TTM`、`PB_MRQ`、`PEG_CAR`、`TRADE_DATE`（滞后数日） |

**可靠性审计结论**：
- ③④ 为**事实类**（最可靠）；①② 为**观点类**（明星股可靠、冷门股失效）
- **冷门股覆盖缺口实锤**：华英农业(002321)、ST岩石(600696) 均无 2026E 预测 → 无锚降级机制必须实现
- 互为兜底：①②双失时 ③④ 照常工作，温度计降级不失明
- 卖方乐观偏差仍在（聚合消个体噪音、消不掉群体偏差）→ 成色标签强制标注

### 2.6 推荐接口组合（v2 更新：每股核心 10 个）

```
核心（MVP必做，每股10个请求 × 5只 = 50请求）:
  行情(ulist) · 资讯(A1) · 财报预约(B1) · 分红(B2) · 解禁(B3)
  · 公告(C1) · 两融(C7) · 一致预期(C11) · 估值历史(RPT_VALUEANALYSIS_DET)
  · 研报评级(C10，读最新观点与分歧)

可选（Phase 2）: 增减持(C3) · 龙虎榜(C5) · 大宗(C6) · 调研(C9)
```

### 2.7 已知陷阱（实现时必读）

1. datacenter 接口**不传 `sortColumns`**（传错列名报 9501），客户端自行排序
2. 解禁/分红返回全量历史 → 客户端按日期过滤（近90天 / 未来180天）
3. 增减持返回时间正序 → 取最新需处理
4. 资讯流混入泛资讯 → 双重过滤
5. 估值历史需拉约1250条（5年日频）算分位 → 响应约百KB级，客户端计算
6. F10 盈利预测对冷门股返回空 → 必须走无锚降级路径

## 3. 报告形态设计（v2 新增）

### 3.1 版面结构（PushPlus 版）

```
推送标题: 🌅 早餐FM日报 | {日期} | {大盘预判} | 自选: {股名🔴/🟡}... 其余🟢
                                                           ↑ 标签聚合，未打开即知有事没事

（🌍 全球要闻 / 📊 隔夜市场 / 🧠 逻辑分析 / 🎯 A股预判 — 现有板块不变）

## 🔍 自选股观察
### {股名} {代码} ｜ {现价} ({涨跌幅}%)  ｜ {状态标签+理由}
   📰 要闻解读（仅🟡🔴展开）
   📅 未来日历 ｜ 💰 资金与预期锚 ｜ 🌡 预期温度计
   🧭 小结（对持仓逻辑的影响，一句）
```

### 3.2 状态标签体系（结论层，规则主裁判）

**四个标签**：🔴重大变化 / 🟡有一事需关注 / 🟢无重大变化 / ⚪数据缺失

**核心机制**：
- **规则引擎主裁判**：数值阈值+关键词触发，确定性、可审计、可解释（标签理由=命中的规则名）
- **默认即绿**：无事不是判断出来的，是"什么都没发生"的自然结果
- **AI 仅有升级权**：可把 🟢 提到 🟡（遇到规则没覆盖但重要的事），**只能升不能降**
- **⚪ ≠ 🟢**：「确认无事」和「不知道有没有事」严格区分——接口失败标 ⚪ 并提示自查，禁止伪装成没事
- 标签永远带一句话理由，禁止孤零零的颜色

**触发规则表**（初始版，试运行后校准）：

```
🔴 触发:
  - 业绩预告/快报隐含增速 vs 一致预期偏差 > 10%
  - 立案调查/处罚/退市风险类公告标题命中
  - 停复牌、并购重组、重大合同公告
  - 7日内解禁且解禁市值/流通市值 > 3%
  - 龙虎榜上榜 / 股东增减持超阈值

🟡 触发:
  - 有一般性公告/资讯（未达🔴）
  - 财报/除权/说明会等节点倒计时 ≤ 7天
  - 融资余额5日变化 > ±5%
  - 研报评级调整 / 一致预期单月修正 > ±3%

🟢: 以上均未命中（默认值）
⚪: 任一核心接口失败
```

### 3.3 AI 四动作与三禁区（翻译层）

每条 🔴🟡 资讯的解读块按四动作输出：

| 动作 | 内容 | 解决的痛点 |
|------|------|-----------|
| ① 归类定级 | 【类别 · 方向 · 强度 · 脉冲/持续型】 | "重点是什么" |
| ② 黑话翻译 | "主动调整"→少发货清库存 | "这词啥意思" |
| ③ 传导链 | 事件→业务→财务→估值，短期/长期两段论 | "背后的逻辑" |
| ④ 挂锚指路 | 对照一致预期 + 指出下一步盯什么 | "所以呢" |

**三禁区**（写死在 Prompt）：不编数字（所有数字来自采集数据）、不给买卖指令（只说"盯什么"）、不确定必须标注。另配固定话术模板（规则注入，AI 不参与）："该消息昨日盘后发布，今晨先看集合竞价量价再定动作"。

### 3.4 呈现规范

- **无事则沉默**：🟢 三行收工（近48h无重要资讯；资金一句话；下一节点），AI 零参与
- **诚实性约束**：AI 无法判断 price-in 程度时，输出固定验证指引而非装懂
- **成色标签**：锚数据必须带成色（`38家·近六月·昨日更新` / `2家·4个月前·⚠覆盖不足`）

```

## 4. 预期温度计（v2 新增）

### 4.1 设计原理

单一指标各有盲区，四个传感器互测互补：**①给锚、②给趋势、③给验证、④给定价**。

### 4.2 信号组合矩阵（②修正 × ④分位，规则执行）

| | ④ 分位低（价格没付多少） | ④ 分位高（已透支） |
|---|---|---|
| **② 上修** | 🟢 预期差黄金区：基本面变好价格没涨 | 🟡 预期改善已定价，追高性价比低 |
| **② 下修** | 🔴 疑似价值陷阱：低PE是市场提前知道要坏 | 🔴 戴维斯双杀进行中，最危险象限 |

### 4.3 数据质量互校

- ③ 是 ① 的上诉法庭：连续两次财报"低于一致预期" → 规则判定锚系统性偏高 → 自动降成色并在报告中提示"该股一致预期习惯性高估"
- 实测数字与市场数据交叉验证示例：行情实测价 1272.83 ÷ 2026E EPS 67.9 ≈ 18.7x，与 C11 接口 PE2=18.73 互相印证

### 4.4 成色与降级（强制机制）

```
高成色: 样本≥10家 · 更新≤1月      → 正常使用，可下定量结论
中成色: 样本3~9家 · 更新≤3月      → 可用，AI 措辞需"参考"
低成色: 样本<3家 或 更新>3月      → ⚠标注，禁止定量"超/低预期"结论
无锚:   F10无预测（冷门股实锤案例）→ 免锚模式（仅③④两维），禁止编锚
```

### 4.5 边界与诚实声明

- ② 免费接口只回看一个月 → MVP 只能说"本月上修/下修"，"持续上修"需研报时序（扩展项）
- ④ 数据滞后数日；周期股低分位可能是盈利顶部假象 → 必须②交叉，禁止单独使用
- 专业级一致预期（Wind/朝阳永续）付费不可行；免费方案中 F10 聚合即上限，对个人盘前决策精度已足

                        #   单接口失败→该项为空+⚪，不阻断
src/quote_fetcher.py    # （或并入fetcher.py）个股行情，复用ulist端点
src/analyzer.py         # Prompt增加「🔍自选股观察」板块要求（四动作+三禁区）
main.py                 # 行情之后调用watchlist；watchlist为空文件则整体跳过
pusher.py / report_formatter.py  # 不改
```

### 6.3 验收标准（试运行一周，用痛点验收而非功能验收）

1. 每天早上 **2分钟内**处理完 5 只股的信息？
2. 复盘一周，有无**任何一件**该知道却没进报告的事？（失败→补数据源）
3. 随机抽两条 AI 解读对照原文，逻辑是否站得住？（失败→调Prompt或降口吻）

## 7. 实施路径

**Phase 1（MVP）**：watchlist.json + watchlist.py（10个核心接口 + 标签规则引擎 + 温度计计算）+ Prompt 新板块（四动作三禁区）+ PushPlus 链接 + ⚪降级

**Phase 2（复盘闭环 + 增强）**：
- **观察点追踪**（最高优先）：每日"下一步盯什么"存档；次日报告开头加「📌昨日观察点回顾」（进展+当时判断vs实际）——复盘的灵魂
- 日报归档 `data/reports/{日期}.md` + 每周五「本周自选股主线」AI提炼
- 可选接口4项（增减持/龙虎榜/大宗/调研）；公告识别回购与股东大会
- 资讯正文抓取（摘要级）

**使用习惯建议**（工程之外的半条）：每天分诊 🔴🟡 时**先猜后看**——先自己判断"利好利空、为什么"，再读 AI 解读。猜错的那条就是当天的学习点；预测先行的留存率远高于纯阅读。
