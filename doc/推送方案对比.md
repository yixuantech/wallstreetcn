## ✅ 最终选定：飞书群机器人

### 选定理由

1. **完全免费，无限条数**
2. **富卡片排版**：比微信服务号消息好看得多，支持图片、分栏、按钮
3. **个人可用**：下载飞书 → 注册 → 建群 → 加机器人，无需企业认证
4. **更可控**：自己群里的机器人，不依赖第三方服务号

### 设置步骤

1. 手机下载飞书APP，注册登录
2. 创建一个私人群聊（只有自己）
3. 群设置 → 群机器人 → 添加机器人 → 自定义机器人
4. 复制 Webhook URL（格式：`https://open.feishu.cn/open-apis/bot/v2/hook/xxx`）

### API

```python
import requests

def push_feishu(webhook_url, title, content):
    """飞书群机器人推送"""
    data = {
        "msg_type": "interactive",
        "card": {
            "header": {
                "title": {
                    "tag": "plain_text",
                    "content": title
                }
            },
            "elements": [
                {
                    "tag": "markdown",
                    "content": content
                }
            ]
        }
    }
    resp = requests.post(webhook_url, json=data)
    return resp.json()
```

### 飞书卡片示例

```python
def push_feishu_rich(webhook_url, date, verdict, report_sections):
    """飞书富卡片推送 - 带颜色标记"""
    data = {
        "msg_type": "interactive",
        "card": {
            "header": {
                "title": {"tag": "plain_text", "content": f"🌅 早餐FM日报 | {date}"},
                "template": _verdict_color(verdict)  # 蓝色/绿色/红色
            },
            "elements": [
                {"tag": "markdown", "content": report_sections["headline"]},
                {"tag": "hr"},
                {"tag": "markdown", "content": report_sections["market"]},
                {"tag": "hr"},
                {"tag": "markdown", "content": report_sections["logic"]},
                {"tag": "hr"},
                {"tag": "markdown", "content": report_sections["prediction"]},
            ]
        }
    }
    resp = requests.post(webhook_url, json=data)
    return resp.json()

def _verdict_color(verdict):
    """根据预判方向返回卡片颜色"""
    if "多" in verdict:
        return "green"    # 看多
    elif "空" in verdict:
        return "red"      # 看空
    else:
        return "blue"     # 看平
```

## 其他方案（未选用，仅作参考）

### Server酱 Turbo

- 关注「方糖」服务号 → 拿SendKey → POST推送
- 免费版5条/天，付费¥50/年100条/天
- 支持Markdown
- 缺点：免费额度有限，排版不如飞书卡片

### PushPlus

- 关注公众号 → 拿Token → POST推送
- 免费版200条/天，付费¥30/年
- 支持Markdown/HTML
- 缺点：同样是服务号消息，排版简单

### 企业微信机器人

- 需注册企业微信 → 建群 → 加机器人
- 完全免费无限量
- 缺点：个人注册企业微信较麻烦
