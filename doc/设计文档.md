# 华尔街见闻早餐FM 自动化报告 — 设计文档

> 最后更新：2026-06-27

## 1. 项目概述

### 1.1 目标

每个交易日盘前自动完成以下流程：

**抓取华尔街见闻「早餐FM」文章 → AI梳理总结 → 生成结构化报告 → 飞书推送**

### 1.2 核心价值

- 盘前5分钟掌握全球市场要闻，无需手动浏览
- AI深度分析新闻内在逻辑和市场影响，而非简单摘要
- 飞书即时推送，零操作成本

### 1.3 关键决策记录

基于前期调研（[API逆向结果.md](API逆向结果.md) / [推送方案对比.md](推送方案对比.md)），关键决策如下：

| 决策项 | 选定方案 | 理由 |
|--------|---------|------|
| 数据获取 | 直接调用API（非爬虫） | API返回结构化JSON，无需登录/Token，早餐FM免费全文可获取 |
| AI模型 | DeepSeek-V3（默认）/ R1（可选） | 国内直连、成本极低（≈¥1/月）、金融理解力强 |
| 推送通道 | 飞书群机器人 | 完全免费无限量、富卡片排版好看、个人可用 |
| 调度方案 | Linux服务器cron | 自有服务器7×24在线，最可靠最简单 |
| 开发语言 | Python | 脚本类任务最自然，生态丰富 |
| 付费墙策略 | 仅使用免费内容（早餐FM） | 已实测验证早餐FM `is_priced=false` 全文~7800字可获取，无需VIP |

## 3. 模块详细设计

### 3.1 数据获取模块 (`fetcher.py`)

#### 3.1.1 API端点

| 用途 | 方法 | URL | 必需Headers |
|------|------|-----|------------|
| 早餐FM列表 | GET | `https://api-one-wscn.awtmt.com/apiv1/content/information-flow?channel=breakfast&accept=article&limit=5&action=upglide` | Origin + Referer |
| 文章详情 | GET | `https://api-one-wscn.awtmt.com/apiv1/content/articles/{id}?extract=0&accept_theme=theme%2Cpremium-theme&remove_disclaimer=1` | Origin + Referer |
| 市场行情 | GET | `https://api-ddc-wscn.awtmt.com/market/real?prod_code={codes}&fields=prod_name,last_px,px_change,px_change_rate,price_precision,securities_type` | Origin + Referer |

#### 3.1.2 数据模型

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class BreakfastArticle:
    """早餐FM文章"""
    id: int
    title: str
    uri: str
    content_html: str          # 原始HTML正文
    content_text: str          # 纯文本正文（供AI处理）
    display_time: int          # 发布时间戳
    is_priced: bool            # 是否付费
    audio_uri: Optional[str]   # 音频地址

@dataclass
class MarketQuote:
    """市场行情"""
    code: str                  # 产品代码
    name: str                  # 产品名称
    last_px: float             # 最新价
    px_change: float           # 涨跌额
    px_change_rate: float      # 涨跌幅%
    securities_type: str       # 类型
```

#### 3.1.3 关键逻辑

- **文章去重**：通过文章ID判断是否已处理过（避免重复推送）
- **免费校验**：检查 `is_priced` 字段，跳过付费文章
- **日期校验**：对比 `display_time` 与当天日期，确保获取的是当天文章
- **HTML清洗**：用 `BeautifulSoup` 去除标签，提取纯文本供AI使用

### 3.3 推送模块 (`pusher.py`)

#### 3.3.1 飞书机器人

```python
class FeishuPush:
    """飞书群机器人推送"""

    def __init__(self, webhook_url: str):
        self.webhook_url = webhook_url

    def push(self, title: str, content: str, verdict: str = ""):
        """发送飞书卡片消息"""
        data = {
            "msg_type": "interactive",
            "card": {
                "header": {
                    "title": {"tag": "plain_text", "content": title},
                    "template": self._verdict_color(verdict)
                },
                "elements": [
                    {"tag": "markdown", "content": content}
                ]
            }
        }
        resp = requests.post(self.webhook_url, json=data)
        return resp.json()

    def _verdict_color(self, verdict: str) -> str:
        """根据预判方向返回卡片颜色"""
        if not verdict:
            return "blue"
        if "多" in verdict:
            return "green"
        elif "空" in verdict:
            return "red"
        return "blue"
```

#### 3.3.2 推送策略

- **标题格式**：`🌅 早餐FM日报 | {date} | {预判}`
- **卡片颜色**：看多=绿色，看空=红色，看平=蓝色
- **失败重试**：重试2次，间隔5秒

### 3.4 调度与编排模块 (`main.py`)

#### 3.4.1 主流程

```python
def run():
    """主流程"""
    # 1. 获取最新早餐FM文章
    article = fetcher.get_latest_breakfast()
    if not article:
        log("今日暂无早餐FM文章，退出")
        return

    # 2. 去重检查（通过文章ID判断）
    if is_already_processed(article.id):
        log(f"文章 {article.id} 已处理过，退出")
        return

    # 3. 获取市场行情（可选）
    market_data = fetcher.get_market_quotes()

    # 4. AI分析生成报告
    report = analyzer.analyze(article.content_text, market_data)

    # 5. 飞书推送
    verdict = extract_verdict(report)
    title = f"🌅 早餐FM日报 | {today()} | {verdict}"
    pusher.push(title, report, verdict)

    # 6. 记录已处理
    mark_processed(article.id)
```

## 5. 错误处理策略

| 场景 | 处理方式 |
|------|---------|
| 早餐FM文章未发布 | 静默退出，日志记录 |
| API请求失败 | 重试3次，间隔5/15/30秒（指数退避） |
| AI API超时 | 重试2次；仍失败则推送"AI分析暂不可用"通知 |
| 推送失败 | 重试2次；仍失败则记录日志 |
| 付费文章 | 跳过，不推送 |
| HTML解析异常 | 降级：直接发送原始文本摘要 |

## 7. 安全注意事项

1. **API Key安全**：密钥通过.env文件管理，不提交到git
2. **请求频率**：遵守网站请求间隔，避免被IP封禁

4. **错误信息脱敏**：推送的错误通知不包含API Key等敏感信息
