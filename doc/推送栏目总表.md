# 推送栏目与时刻总表

## 二、各栏目内容明细

### 🌅 晨报（盘前预判 + 认知输入）

| 板块 | 内容 | 生成方 |
|------|------|--------|
| 🌍 全球要闻 | 隔夜要闻5-8条+影响方向+**历史模式锚**（上次同类事件市场怎么走） | 规则+AI |
| 📌 主线追踪 | 主线编号+周数+状态+本周进展（固定位置滚动，新主线诞生/旧主线终结有记录） | AI+归档 |
| 📊 隔夜市场表现 | 全球股/汇/商品/债全表 | 规则 |
| 🧠 内在逻辑分析 | 事件关联与主线联动 | AI |
| 🎯 今日A股预判 | 方向判断+关注板块+风险点 | AI |
| 🔍 自选股观察·晨巡 | 标签分诊🔴🟡🟢⚪+温度计+48h资讯逐条解读+公告+日历节点 | 规则+AI |
| 📅 今日日历 | 今日将发布数据/事件一行 | 规则 |

### 📊 数据解读（宏观数据专题，教学主打）

| 板块 | 内容 | 生成方 |
|------|------|--------|
| 三对照 | 实际 vs 预期 vs 前值，超预期幅度 | 规则 |
| 📊 历史位置 | 近5年分位+连续改善/恶化月数 | 规则 |
| 📚 概念卡 | 该指标是什么/为什么重要/历史区间（首次遇到展开，规则触发） | 规则+AI |
| 💬 说人话 | 数字背后的经济现象 | AI |
| 🔗 传导链 | 数据→资产→板块 | AI |
| 🧭 持仓联动 | 传导到自选股的具体含义 | AI |

覆盖：中国 PMI×2/CPI/PPI/社融/信贷/出口/社零/工业增加值/LPR；美国 非农/CPI/FOMC。
时点规则（同一栏目两个档）：中国数据（日间发布）→当日18:30；美国数据（北京晚间发布）→次日07:45。

### ⚡ 午间快讯（盘中巡检，护栏铁律）

每条异动必须三件套：**异动+定级(利好/利空/中性)+下午盯什么**。禁止裸价格播报（防诱导情绪化操作）。无定级不推。

| 板块 | 内容 | 触发 |
|------|------|------|
| 新增资讯/公告速报 | 上午发布的🟡级以上事项，一句话定性 | 规则判定 |
| 盘中异动 | 自选股±3%波动，三件套呈现 | 规则判定 |

### 🌙 晚报（盘后复盘 + 判断校准）

| 板块 | 内容 | 生成方 |
|------|------|--------|
| 📊 今日复盘 | A股收盘全景：指数/量能/涨跌家数/领涨领跌板块 | 规则 |
| 🌡️ 市场情绪刻度 | 情绪分值(0-100)+构成（涨跌家数/涨停跌停/量能）+历史同类日次日表现——数据锚定对抗情绪 | 规则 |
| ✅ 判断记分牌 | 晨报预判验证（方向+板块兑现/落空/意外）**+全球要闻方向标注验证**（"利好黄金"→实际+1.3%✓） | 规则+AI |
| 🔍 自选股收盘 | 当日表现+资金+观察点状态（挂起⏳/兑现✓/失效✗） | 规则+AI |
| 📅 明日展望 | 明日数据/事件+今晚隔夜关注 | 规则 |

### 🚨 紧急警报（夜巡，只响🔴）

| 板块 | 内容 | 触发 |
|------|------|------|
| 🔴事件 | 晚间公告关键词：立案/停牌/预亏/重组/退市警示/重大减持 | 规则 |
| 一句话影响+明日关注 | 事件定性+次日开盘应对关注点 | AI |

🟡级晚间公告不推，留给次日晨报。

### 📖 周报（周六周测：周期性固化认知）

| 板块 | 内容 | 生成方 |
|------|------|--------|
| 📌 主线周演进 | 每条主线本周变化/状态迁移/新诞生与终结 | AI+归档 |
| ✅ 记分周汇总 | 本周判断验证胜率（预判+方向标注）+最有价值的对错各一条 | 规则+AI |
| 🔍 观察点结算 | 本周观察点兑现/失效/挂起汇总 | 规则+AI |
| 📅 下周日历 | 数据/事件/财报预约+关键观察点 | 规则 |

## 四、教育闭环

```
晨报（主线地图+模式样本+概念卡）→ 晚报（判断记分牌校准）→ 周报（周期固化）
      输入模式库              →        校准判断          →      形成直觉
```

## 五、实现顺序

```
1. main.py 报告落盘（地基，含晨报文本供晚报验证用）  ← 半小时
2. 🌙 晚报（复盘+情绪刻度+判断记分牌=观察点追踪载体）  ← 1-2天
3. ⚡午间快讯 + 🚨夜巡（复用采集+触发条件）           ← 1天
4. 📊 数据解读（先侦察预期值源/社融报表名）           ← 2-3天
5. 📌 主线追踪（依赖归档积累，随周报一起）            ← 2-3天
6. 全天调度（任务计划程序）
```
